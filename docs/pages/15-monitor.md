# 15. 실시간 모니터링

- **경로:** `/monitor`
- **목적:** 영상을 보며 안전 관련 감지 상태 확인
- **화면 기준:** 최종 보라/노랑 목업(라벤더 배경·흰 카드·큰 CTA)

## UI 구성
- 상단 실시간 스트림(영상 소리 ON/OFF, 전체화면, 품질 변경).
- 연결 상태 `실시간/연결 중/끊김/확인 불가`.
- 위험 팝업이 영상 위에 우선 표시.
- 수면 환경 점검: 아기 자세, 얼굴 노출, 주변 물체, 가장자리 접근.
- 환경 센서 카드: 온도/습도 등 연결된 센서만 실제 수치 제공.

## 인터랙션 및 이동
- 감지 이벤트 클릭 → 16 위험 상세.
- 소리 버튼은 **영상 오디오**만 제어하고 위험 알림 소리는 영향 없음.
- 재연결 버튼 → 스트림 재시도.

## 데이터/상태 및 예외
- 연결 끊김/화면 가림 시 `확인 불가`, 안전 판단 금지.
- 얼굴 가림 감지는 의심 신호로 표기하며 질식 진단으로 표기 금지.
- 센서 미연결 시 `미연결·직접 확인` 카드.
- 접근 구역은 서버에서 설정된 경우에만 표시.

## 구현·검수 포인트
- 로딩/빈 상태/오류/접근성을 공통 컴포넌트로 처리.
- 저장·선택 결과는 실제 상태에 반영하고 성공 전에는 완료로 표시하지 않음.
