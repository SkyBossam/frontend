# 17. 더보기·설정

- **경로:** `/more`
- **목적:** 계정과 앱 환경 관리
- **화면 기준:** 최종 보라/노랑 목업(라벤더 배경·흰 카드·큰 CTA)

## UI 구성
- 내 계정, 알림 설정, 개인정보 및 데이터, 도움말, 로그아웃.
- 영상 소리/품질 설정(선택).
- 알림 소리 테스트 및 권한 상태 확인.

## 인터랙션 및 이동
- 알림 설정 → 설정 시트.
- 로그아웃 시 확인 팝업, 세션 만료 후 `/welcome`.

## 데이터/상태 및 예외
- 위험 알림 음소거 정책 확정 전까지 관련 토글 비노출.
- 등록 아이 정보 삭제는 명시적 확인 및 백엔드 정책 필요.

## 구현·검수 포인트
- 로딩/빈 상태/오류/접근성을 공통 컴포넌트로 처리.
- 저장·선택 결과는 실제 상태에 반영하고 성공 전에는 완료로 표시하지 않음.
