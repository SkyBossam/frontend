# 11. 맞춤 행동 추천

- **경로:** `/children/cries/:eventId/recommendations`
- **목적:** 행동 우선순위와 근거를 명확히 제시
- **화면 기준:** 최종 보라/노랑 목업(라벤더 배경·흰 카드·큰 CTA)

## UI 구성
- 상단 “추천 행동을 시도해 보세요”.
- 최우선 추천 카드(노란 강조): 행동명, 설명, 단계별 가이드, 과거 사례 기반 추천 이유.
- 대안 추천 리스트(안아주기, 수면 환경 조정, 기저귀 확인, 상태 확인 등).
- `이 행동으로 시작하기` 버튼.

## 인터랙션 및 이동
- 각 추천 선택 → 행동 상세 확장/선택.
- 시작하기 → 12로 이동하며 선택 행동을 초기 체크.

## 데이터/상태 및 예외
- 추천이 없을 때 기본 행동 안내.
- 베개·느슨한 이불·수면 자세 고정 도구 등 위험한 조언 금지.
- AI 추천은 참고용이며 부모의 직접 확인을 우선.

## 구현·검수 포인트
- 로딩/빈 상태/오류/접근성을 공통 컴포넌트로 처리.
- 저장·선택 결과는 실제 상태에 반영하고 성공 전에는 완료로 표시하지 않음.
