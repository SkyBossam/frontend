# 04. 알림 설정

- **경로:** `/onboarding/notifications`
- **목적:** 위험·울음 알림을 받을 수 있도록 준비
- **화면 기준:** 최종 보라/노랑 목업(라벤더 배경·흰 카드·큰 CTA)

## UI 구성
- 종 아이콘, 위험 알림 소리·울음 알림 소리 설정.
- `알림 소리 테스트`, `완료` 버튼.
- 시스템 알림 권한 상태 설명.

## 인터랙션 및 이동
- 테스트 → 샘플 소리 재생, 실제 위험 이벤트 생성 금지.
- 완료 → `/home`; 알림 권한 거부 시 설정 안내.

## 데이터/상태 및 예외
- 브라우저/OS 정책에 따라 소리 재생이 제한되면 안내.
- **긴급 알림 음소거 허용 정책은 미확정**, 위험 알림 사운드 완전 차단 옵션은 노출하지 않는다.
- 웹캠 연결 단계 없음.

## 구현·검수 포인트
- 로딩/빈 상태/오류/접근성을 공통 컴포넌트로 처리.
- 저장·선택 결과는 실제 상태에 반영하고 성공 전에는 완료로 표시하지 않음.
