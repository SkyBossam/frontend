# 06. 오늘의 요약

- **경로:** `/home/summary`
- **목적:** 일별 수면·울음·루틴 결과 확인
- **화면 기준:** 최종 보라/노랑 목업(라벤더 배경·흰 카드·큰 CTA)

## UI 구성
- 날짜 및 아이 프로필.
- 수면 시간, 울음 이벤트 수, 루틴 진행 횟수(데이터가 있을 때만).
- 시간대별 타임라인: 감지 시각, 행동, 반응.
- 최근 이벤트 카드 및 상세 이동.

## 인터랙션 및 이동
- 날짜 변경 → 해당 일자 데이터 요청.
- 울음 카드 선택 → 상세(10).
- 루틴 카드 선택 → 루틴(08).

## 데이터/상태 및 예외
- 시간 계산 기준 타임존 Asia/Seoul.
- 기록이 없을 때 “오늘 기록이 없어요”.
- 통계는 계측·기록 기반으로만 집계.

## 구현·검수 포인트
- 로딩/빈 상태/오류/접근성을 공통 컴포넌트로 처리.
- 저장·선택 결과는 실제 상태에 반영하고 성공 전에는 완료로 표시하지 않음.
