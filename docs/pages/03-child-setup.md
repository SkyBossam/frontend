# 03. 아이 기본 정보 등록

- **경로:** `/onboarding/child`
- **목적:** 돌봄 대상 생성
- **화면 기준:** 최종 보라/노랑 목업(라벤더 배경·흰 카드·큰 CTA)

## UI 구성
- 프로필 이미지(선택), 이름(필수), 생년월일(필수), 성별(선택/미응답 가능).
- 진행 단계 표시 및 노란색 `다음` 버튼.

## 인터랙션 및 이동
- 값 검증 및 저장 → `/onboarding/notifications`; 뒤로가기 → 회원가입.

## 데이터/상태 및 예외
- 미래 생년월일 차단, 서버 저장 실패 복구, 사진 업로드 권한 오류.
- 월령은 생년월일로 계산. 개인정보 최소 수집.

## 구현·검수 포인트
- 로딩/빈 상태/오류/접근성을 공통 컴포넌트로 처리.
- 저장·선택 결과는 실제 상태에 반영하고 성공 전에는 완료로 표시하지 않음.
