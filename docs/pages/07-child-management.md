# 07. 우리 아이 관리

- **경로:** `/children`
- **목적:** 아기별 루틴·울음·행동 이력 진입 허브
- **화면 기준:** 최종 보라/노랑 목업(라벤더 배경·흰 카드·큰 CTA)

## UI 구성
- 아이 사진, 이름/월령, `정보 수정` 버튼.
- 메뉴 `오늘의 루틴`, `울음 관리`, `맞춤 행동 관리`, `이력 보기`.
- 하단 탭과 상태 요약 카드.

## 인터랙션 및 이동
- 루틴 → 08, 울음 → 09, 맞춤 행동 → 최근 추천 목록(11, 이벤트 필요), 이력 → 09 필터/06 요약.
- 정보 수정 → 프로필 편집 시트.

## 데이터/상태 및 예외
- 추천 이벤트가 없으면 행동 추천 빈 상태 표시.
- 아이 변경은 childId 기반 데이터 갱신.

## 구현·검수 포인트
- 로딩/빈 상태/오류/접근성을 공통 컴포넌트로 처리.
- 저장·선택 결과는 실제 상태에 반영하고 성공 전에는 완료로 표시하지 않음.
