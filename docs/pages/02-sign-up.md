# 02. 회원가입/로그인

- **경로:** `/signup`, `/login`
- **목적:** 계정 생성과 인증
- **화면 기준:** 최종 보라/노랑 목업(라벤더 배경·흰 카드·큰 CTA)

## UI 구성
- 헤더 `회원가입` 또는 `로그인`.
- 이메일·비밀번호 입력 필드, 비밀번호 표시 토글.
- 보라색 제출 버튼, 화면 전환 링크.
- Apple/Google 로그인은 실제 공급자 설정 여부에 따라 표기.

## 인터랙션 및 이동
- 폼 검증 후 회원가입 성공 → `/onboarding/child`.
- 로그인 성공 → 등록 아이 있으면 `/home`, 없으면 `/onboarding/child`.

## 데이터/상태 및 예외
- 이메일 형식, 비밀번호 정책, 중복 계정, 자격증명 오류, 진행 중 제출 잠금.
- 외부 로그인 미구현이라면 버튼 숨김(장식용 금지).

## 구현·검수 포인트
- 로딩/빈 상태/오류/접근성을 공통 컴포넌트로 처리.
- 저장·선택 결과는 실제 상태에 반영하고 성공 전에는 완료로 표시하지 않음.
