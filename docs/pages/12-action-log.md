# 12. 시도 행동 기록

- **경로:** `/children/cries/:eventId/actions`
- **목적:** 실제로 취한 행동을 저장
- **화면 기준:** 최종 보라/노랑 목업(라벤더 배경·흰 카드·큰 CTA)

## UI 구성
- 질문 “어떤 행동을 시도했나요?”
- 체크박스: 수면 환경 조정, 안아주기, 백색소음, 자세·상태 확인, 기저귀 상태 확인, 기타(직접 입력).
- `시도하지 않음` 선택 가능, 추가 메모(선택), 노란 `다음`.

## 인터랙션 및 이동
- 체크 선택 시 로컬 임시 저장.
- 다음 → 13(저장 전).
- 뒤로 → 추천 화면, 선택 유지.

## 데이터/상태 및 예외
- 시도 행동이 없을 경우 명시적 `시도하지 않음`으로 기록.
- 복수 선택 허용; 기타 선택 시 텍스트 입력.
- 다른 아이/이벤트의 기록과 혼합 금지.

## 구현·검수 포인트
- 로딩/빈 상태/오류/접근성을 공통 컴포넌트로 처리.
- 저장·선택 결과는 실제 상태에 반영하고 성공 전에는 완료로 표시하지 않음.
