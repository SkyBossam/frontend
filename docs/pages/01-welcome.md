# 01. 시작 화면

- **경로:** `/welcome`
- **목적:** 브랜드 소개와 회원가입/로그인 진입
- **화면 기준:** 최종 보라/노랑 목업(라벤더 배경·흰 카드·큰 CTA)

## UI 구성
- 상단 로고·캐릭터(자는 아기와 구름), 브랜드명 `BabySense`.
- 문구: “우리 아기의 오늘도, 더 안전하고 더 편안하게”.
- 하단 `시작하기` 보라 버튼, `로그인` 텍스트 링크.

## 인터랙션 및 이동
- 시작하기 → `/signup`; 로그인 → `/login`(02 문서의 로그인 모드).

## 데이터/상태 및 예외
- 인증 사용자라면 `/home` 자동 이동.
- 애니메이션은 최소화, 이미지 실패 시 로고 대체 텍스트.

## 구현·검수 포인트
- 로딩/빈 상태/오류/접근성을 공통 컴포넌트로 처리.
- 저장·선택 결과는 실제 상태에 반영하고 성공 전에는 완료로 표시하지 않음.
