# 08. 오늘의 루틴

- **경로:** `/children/routines`
- **목적:** 수면·기상·놀이·달래기 계획 관리
- **화면 기준:** 최종 보라/노랑 목업(라벤더 배경·흰 카드·큰 CTA)

## UI 구성
- 날짜, 루틴 카드 목록과 완료 체크.
- `루틴 추가` 버튼, 제목/종류/시간/메모 편집 시트.
- 진행 중·완료·예정 구분 및 팁 카드.

## 인터랙션 및 이동
- 추가/수정/삭제/완료 체크는 서버 반영 후 갱신.
- 뒤로가기 → `/children`.

## 데이터/상태 및 예외
- 필수 입력: 제목, 종류. 시간은 선택.
- 같은 루틴 중복 클릭 시 중복 저장 방지.
- 별도의 수유 이력 관리 UI 추가 금지.

## 구현·검수 포인트
- 로딩/빈 상태/오류/접근성을 공통 컴포넌트로 처리.
- 저장·선택 결과는 실제 상태에 반영하고 성공 전에는 완료로 표시하지 않음.
