# 10. 울음 상세

- **경로:** `/children/cries/:eventId`
- **목적:** 감지 내용과 AI 추정 근거 확인
- **화면 기준:** 최종 보라/노랑 목업(라벤더 배경·흰 카드·큰 CTA)

## UI 구성
- 울음 감지 시각/지속 시간.
- 오디오 재생은 저장 및 권한이 허용될 때만 표시.
- `AI 분석 결과`는 원인 후보(졸림, 배고픔 가능성, 불편함, 상태 확인 필요)를 근거와 함께 나열.
- 핵심 보라 CTA `추천 행동 확인하기`.

## 인터랙션 및 이동
- 추천 확인 → 11.
- 기존 피드백이 있으면 `이전 대응 결과 보기` 노출.

## 데이터/상태 및 예외
- 모델 실패 시 원인 단정 없이 일반 확인 체크리스트.
- 후보별 수치는 검증된 모델 점수만 표시.
- 의료 진단/응급 판단을 AI가 대체하지 않도록 안내.

## 구현·검수 포인트
- 로딩/빈 상태/오류/접근성을 공통 컴포넌트로 처리.
- 저장·선택 결과는 실제 상태에 반영하고 성공 전에는 완료로 표시하지 않음.
