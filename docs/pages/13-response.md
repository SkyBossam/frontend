# 13. 아이 반응 선택

- **경로:** `/children/cries/:eventId/response`
- **목적:** 행동 후 변화 측정
- **화면 기준:** 최종 보라/노랑 목업(라벤더 배경·흰 카드·큰 CTA)

## UI 구성
- “아이가 울음을 그쳤나요?”
- 라디오 단일선택: `그쳤어요`, `줄었어요`, `계속 울어요`, `모르겠어요`.
- 결과 설명 + 노란 `기록하기`.

## 인터랙션 및 이동
- 한 가지 선택 후 기록하기 → `POST /events/:id/feedback` → 성공 시 14.
- 실패 시 현재 입력 유지 + 재시도.

## 데이터/상태 및 예외
- 미선택 제출 불가.
- `계속 울어요` 선택 시 추가 직접 확인/도움 요청 안내를 표시할 수 있으나 진단 금지.
- 연속 탭 중복 저장 방지.

## 구현·검수 포인트
- 로딩/빈 상태/오류/접근성을 공통 컴포넌트로 처리.
- 저장·선택 결과는 실제 상태에 반영하고 성공 전에는 완료로 표시하지 않음.
