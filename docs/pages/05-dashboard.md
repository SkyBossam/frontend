# 05. 메인 대시보드

- **경로:** `/home`
- **목적:** 현재 위험과 즉시 필요한 행동을 최우선 표시
- **화면 기준:** 최종 보라/노랑 목업(라벤더 배경·흰 카드·큰 CTA)

## UI 구성
- 상단 보호자/아이 프로필과 알림 아이콘.
- 헤드라인: 위험 시 “지안이의 얼굴 가림이 감지됐어요. 지금 확인해 주세요.”, 정상 시 “새로운 감지 알림이 없어요.”
- 경고 배너: `즉시/주의/안정/확인 불가` 텍스트+아이콘, 최근 감지 시각, `확인하러 가기` CTA.
- 웹캠 미리보기, `실시간 모니터링` 링크.
- 오늘 루틴(수면/놀이/달래기) 요약.
- 울음·수면 타임라인(발생→시도→결과), `오늘의 요약` 링크.

## 인터랙션 및 이동
- 경고 CTA → 위험 상세 모달(16) 또는 `/monitor`.
- 미리보기 → `/monitor`; 루틴 → `/children/routines`; 타임라인 울음 → `/children/cries/:eventId`; 요약 → `/home/summary`.

## 데이터/상태 및 예외
- 긴급 이벤트가 있으면 최상단에 배치.
- 여러 아이 사용 시 위험도 내림차순(확장).
- 미확인 이벤트 수와 처리 상태를 분리.
- 스트림 미연결 시 플레이스홀더를 표시하되 안전 상태로 단정하지 않음.

## 구현·검수 포인트
- 로딩/빈 상태/오류/접근성을 공통 컴포넌트로 처리.
- 저장·선택 결과는 실제 상태에 반영하고 성공 전에는 완료로 표시하지 않음.
