# 09. 울음 관리 목록

- **경로:** `/children/cries`
- **목적:** 울음 이벤트와 대응 결과 조회
- **화면 기준:** 최종 보라/노랑 목업(라벤더 배경·흰 카드·큰 CTA)

## UI 구성
- 상단 필터 전체/오늘/지난 7일.
- 행: 감지 시각, 지속 시간, 추정 원인 후보, 처리 상태(`미기록/기록 완료`).
- 상세 진입 화살표, 비어 있을 때 안내.

## 인터랙션 및 이동
- 각 이벤트 선택 → `/children/cries/:eventId`.
- 필터 전환 시 쿼리 갱신, 스크롤 유지.

## 데이터/상태 및 예외
- 지속 시간 미확정 시 `진행 중`으로 표시.
- 배고픔·아픔은 추정 원인일 뿐 확정 판단 아님.

## 구현·검수 포인트
- 로딩/빈 상태/오류/접근성을 공통 컴포넌트로 처리.
- 저장·선택 결과는 실제 상태에 반영하고 성공 전에는 완료로 표시하지 않음.
