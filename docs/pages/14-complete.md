# 14. 기록 완료

- **경로:** `/children/cries/:eventId/complete`
- **목적:** 저장된 행동과 결과 확인
- **화면 기준:** 최종 보라/노랑 목업(라벤더 배경·흰 카드·큰 CTA)

## UI 구성
- 구름 캐릭터·“기록이 저장되었어요”.
- 이벤트 시각, 선택한 행동, 아이 반응, 기록 시각 요약 카드.
- 보라 `확인` 및 `이력에서 보기` 버튼.

## 인터랙션 및 이동
- 확인 → `/children`; 이력 → `/children/cries/:eventId`.

## 데이터/상태 및 예외
- 실제 저장 성공 응답 후에만 노출.
- 새로고침해도 저장된 기록 조회 가능해야 함.

## 구현·검수 포인트
- 로딩/빈 상태/오류/접근성을 공통 컴포넌트로 처리.
- 저장·선택 결과는 실제 상태에 반영하고 성공 전에는 완료로 표시하지 않음.
