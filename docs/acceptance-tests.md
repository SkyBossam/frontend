# 핵심 인수 테스트

1. 신규 가입→아이 정보 등록→알림 테스트→홈 진입. **카메라 연결 온보딩은 나타나지 않는다.**
2. 홈에 새 위험 이벤트 수신 시 가장 높은 위험 수준을 헤드라인과 경고 카드로 표시하고 '확인하러 가기'가 상세를 연다.
3. 위험 모달 닫기·확인하러 가기·알림 열람 후에도 이벤트는 자동 해결되지 않는다. '현장 확인 완료'와 결과 선택 시에만 상태 변경.
4. 영상 끊김·화면 가림 시 '확인 불가'를 노출, '안정'이라고 표시하지 않는다.
5. 온도/습도 센서 미연결 시 숫자·안정 배지를 표시하지 않고 '미연결/직접 확인'을 표시한다.
6. 울음 목록의 이벤트를 선택하면 이벤트 ID에 해당하는 상세, 원인 후보, 추천으로 이어진다.
7. 추천 행동 한 개 이상 시도 여부를 입력하고 아이 반응 4개 중 하나를 선택해 저장할 수 있다.
8. 저장 완료 화면에 시도 행동/아이 반응이 표시되며 이력에서 다시 확인 가능하다.
9. 추천 모델 응답이 실패해도 페이지는 오류 안내 및 기본 안내를 제공한다.
10. 아이 여러 명 데이터가 들어와도 요청/기록은 childId로 격리되고 위험도 기준 정렬 확장이 가능하다.
11. 화면을 스크린리더로 읽었을 때 위험 배지와 버튼의 의미를 글자로 확인 가능하다.
12. 이미 해결된 이벤트의 중복 저장과 새로고침 중복 제출을 방지한다.
