# 아이쿠 (aicoo)

보라·노랑 파스텔 모바일 목업과 첨부된 17개 화면 명세를 바탕으로 만든 React + TypeScript 프론트엔드입니다. 모바일에서는 하단 탭, 데스크톱에서는 사이드 메뉴와 2열 대시보드를 사용합니다.

## 실행

Node.js 22 이상에서 프로젝트 폴더를 열어 실행합니다. Windows PowerShell에서는 실행 정책에 영향받지 않는 `npm.cmd`를 사용할 수 있습니다.

```powershell
cd frontend
npm.cmd install
npm.cmd run dev
```

브라우저에서 터미널에 표시된 로컬 주소를 엽니다. 첫 화면의 **지안이의 하루 미리 둘러보기**로 시연 데이터를 확인할 수 있습니다.

```powershell
npm.cmd run build
npm.cmd test
npm.cmd run preview
```

## 구현 범위

- 시작, 회원가입/로그인 UI, 아이 등록·수정·사진 선택, 알림 설정·소리 테스트
- 대시보드, 일별 요약, 아이 관리, 루틴 추가·수정·삭제·완료
- 울음 목록·기간 필터·상세, 추천 행동, 복수 행동 선택, 4가지 반응, 중복 방지 저장과 결과 조회
- 모니터링의 미연결·재연결·화면 가림 상태, 미연결 센서, 위험 상세·현장 확인 결과
- 설정, 기록 JSON 다운로드, 로그아웃, 키보드 접근·모달 포커스 제한, 반응형 레이아웃
- 더보기의 시연 도구로 얼굴 가림 알림 및 AI 분석 실패 상태 확인

## 현재 데이터와 연동 범위

**백엔드와 실제 인증·AI·카메라 스트림은 연결되지 않았습니다.** 가입/로그인은 입력 검증과 온보딩 흐름을 확인하는 로컬 시연입니다. 실제 계정을 만들거나 비밀번호를 보관하지 않습니다. Apple/Google 로그인 버튼은 공급자 연결 전까지 표시하지 않습니다.

`src/store.ts`의 Mock 저장 어댑터를 API 호출로 교체하면 됩니다. 화면은 저장 성공 후에만 상태를 갱신합니다. 기록은 이메일별 브라우저 localStorage에, 로그인 세션과 입력 중인 행동 기록은 sessionStorage에 보관됩니다. 이는 실제 인증이나 개인정보 접근제어를 대신하지 않습니다. 실서비스에는 서버 인증, 권한 검사, 최소 보존 정책을 추가해야 합니다.

카메라가 없을 때 안전을 단정하지 않으며, 온·습도 값도 임의 생성하지 않습니다. 위험 모달 열람·닫기·모니터링 이동은 해결 처리와 분리됩니다. `위험 요소 제거함` 또는 `오탐 / 문제 없음`을 명시적으로 저장해야 해결됩니다. AI 결과는 예시 추정이며 검증되지 않은 백분율은 표시하지 않습니다.

`docs/`는 제공받은 원본 명세를 보존한 폴더입니다. 원본의 BabySense 명칭은 구현 화면에서 사용자 요청에 따라 **아이쿠(aicoo)**로 변경했습니다. API 계약은 `docs/data-contracts.md`를 참고하세요.

## 구조

```text
src/
  main.tsx          앱 셸·URL 라우팅
  pageRegistry.ts   페이지 등록
  pageTypes.ts      페이지 컴포넌트 계약
  context.tsx       세션·상태·저장 트랜잭션
  domain.ts         데이터 타입·날짜·필터·상태 전이
  store.ts          Mock 저장 어댑터
  components.tsx    공통 UI
  components/      여러 페이지에서 사용하는 폼·타임라인
  pages/           기획서 순서의 17개 페이지
  flows/CryFlow.tsx 울음 대응 흐름의 공통 상태
  styles.css       디자인 토큰·반응형 스타일
tests/domain.test.ts 핵심 상태 전이·데이터 격리 테스트
public/baby-demo.png 생성된 시연용 아기 이미지
```

일반 정적 호스팅으로 배포할 때는 모든 앱 경로를 `index.html`로 반환하는 SPA fallback을 설정하세요. Google Fonts 요청이 불가능하면 시스템 글꼴로 표시됩니다.

## 이미지

`public/baby-demo.png`는 내장 imagegen 도구로 생성한 가상의 아기 사진입니다. 실제 카메라 영상이 아니며 UI에 시연 이미지로 표시합니다. 생성 프롬프트는 `docs/image-prompt.txt`에 보관했습니다. 구름 마스코트·로고는 SVG로 구현했습니다.
