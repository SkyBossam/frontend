# 아이쿠 (aicoo)

보라·노랑 파스텔 모바일 목업과 첨부된 17개 화면 명세를 바탕으로 만든 React + TypeScript 프론트엔드입니다. 모바일에서는 하단 탭, 데스크톱에서는 사이드 메뉴와 2열 대시보드를 사용합니다.

## 실행

Node.js 22 이상에서 프로젝트 폴더를 열어 실행합니다. Windows PowerShell에서는 실행 정책에 영향받지 않는 `npm.cmd`를 사용할 수 있습니다.

```powershell
cd frontend
npm.cmd install
npm.cmd run dev
```

브라우저에서 터미널에 표시된 로컬 주소를 엽니다. 첫 화면의 **지안이의 하루 미리 둘러보기**로 시연 데이터를 확인할 수 있습니다.

```powershell
npm.cmd run build
npm.cmd test
npm.cmd run preview
```

## 구현 범위

- 시작, 회원가입/로그인 UI, 아이 등록·수정·사진 선택, 알림 설정·소리 테스트
- 대시보드, 일별 요약, 아이 관리, 루틴 추가·수정·삭제·완료
- 울음 목록·기간 필터·상세, 추천 행동, 복수 행동 선택, 4가지 반응, 중복 방지 저장과 결과 조회
- 모니터링의 미연결·재연결·화면 가림 상태, 미연결 센서, 위험 상세·현장 확인 결과
- 설정, 기록 JSON 다운로드, 로그아웃, 키보드 접근·모달 포커스 제한, 반응형 레이아웃
- 더보기의 시연 도구로 얼굴 가림 알림 및 AI 분석 실패 상태 확인
- `/devices`: 실제 아이쿠 가입·로그인·이메일 인증, 아이 등록·선택, 파이 코드 확인·승인, 기기 상태 조회·연결 해제

## 파이 연결 화면 실행

백엔드를 `http://127.0.0.1:8080`에서 실행한 뒤 `npm run dev`로 프론트를 시작하고 `/devices`를 엽니다. 개발 서버가 `/api/v1`을 백엔드로 프록시합니다. 첫 화면의 **내 파이 연결하기**, 모니터링의 같은 버튼, **더보기 → 기기 연결**에서도 접근할 수 있습니다.

배포 시에는 `.env.example`을 참고해 `VITE_API_BASE_URL=https://실제-백엔드-origin`을 빌드 전에 지정하세요. `/api/v1`은 붙이지 않습니다. 백엔드의 `CORS_ORIGINS`에는 이 프론트의 origin을, `FRONTEND_URL`에는 QR 링크를 열 프론트 주소를 설정합니다. 빈 API 주소는 같은 origin을 사용하므로 프록시 없는 정적 호스팅에서는 실제 API 주소 설정이 필요합니다. `/devices`도 SPA fallback 대상에 포함하세요.

1. 파이에서 `aicoo_device.py pair`를 실행합니다.
2. 보호자가 `/devices`에서 아이쿠 계정으로 로그인하고 이메일을 인증합니다. 로컬 백엔드는 실제 메일 대신 개발용 인증 코드를 화면에 표시합니다.
3. 돌봄 공간·아이를 선택하고 8자리 코드를 입력합니다. 아이가 없으면 등록합니다.
4. 파이와 화면의 기기 확인값을 대조하고 **이 아이에게 연결**을 누릅니다.
5. 파이에서 `aicoo_device.py run`을 실행하면 기기 목록이 온라인으로 갱신됩니다.

파이 설치·자동 실행 안내: [backend/raspberry-pi](https://github.com/SkyBossam/backend/tree/main/raspberry-pi). 연결 코드는 5분 유효하며, `#code=ABCD-2345` 링크는 코드만 미리 채우고 자동 승인하지 않습니다. 기기별 인증 토큰은 브라우저에 전달하지 않습니다. 사용자 인증 토큰은 메모리에만 보관하므로 새로고침 또는 이 페이지를 벗어난 뒤에는 다시 로그인합니다. 사용자 로그아웃은 이미 등록한 파이를 해제하지 않습니다.

기기 목록은 5초마다 실제 서버 응답을 조회합니다. **온라인은 파이의 통신 상태**이며 영상 재생이나 아이의 안전을 의미하지 않습니다. 해제 후 다시 연결할 때는 파이에서 새 코드를 발급합니다.

## 현재 데이터와 연동 범위

**`/devices`는 실제 백엔드와 연결됩니다.** 이 페이지의 계정·아이·기기 정보는 서버에 저장됩니다. 나머지 기존 돌봄 화면의 가입/로그인·대시보드·루틴·울음 기록은 로컬 체험이며, 영상 송출과 AI 추론은 아직 연결되지 않았습니다. 체험 계정은 실제 아이쿠 계정과 별개입니다. Apple/Google 로그인 버튼은 공급자 연결 전까지 표시하지 않습니다.

`src/store.ts`의 Mock 저장 어댑터를 API 호출로 교체하면 됩니다. 화면은 저장 성공 후에만 상태를 갱신합니다. 기록은 이메일별 브라우저 localStorage에, 로그인 세션과 입력 중인 행동 기록은 sessionStorage에 보관됩니다. 이는 실제 인증이나 개인정보 접근제어를 대신하지 않습니다. 실서비스에는 서버 인증, 권한 검사, 최소 보존 정책을 추가해야 합니다.

카메라가 없을 때 안전을 단정하지 않으며, 온·습도 값도 임의 생성하지 않습니다. 위험 모달 열람·닫기·모니터링 이동은 해결 처리와 분리됩니다. `위험 요소 제거함` 또는 `오탐 / 문제 없음`을 명시적으로 저장해야 해결됩니다. AI 결과는 예시 추정이며 검증되지 않은 백분율은 표시하지 않습니다.

`docs/`는 제공받은 원본 명세를 보존한 폴더입니다. 원본의 BabySense 명칭은 구현 화면에서 사용자 요청에 따라 **아이쿠(aicoo)**로 변경했습니다. API 계약은 `docs/data-contracts.md`를 참고하세요.

## 구조

```text
src/
  main.tsx          앱 셸·URL 라우팅
  pageRegistry.ts   페이지 등록
  pageTypes.ts      페이지 컴포넌트 계약
  context.tsx       세션·상태·저장 트랜잭션
  domain.ts         데이터 타입·날짜·필터·상태 전이
  store.ts          기존 돌봄 화면의 Mock 저장 어댑터
  api/deviceClient.ts 실제 계정·아이·기기 API, 메모리 토큰·refresh
  components.tsx    공통 UI
  components/      여러 페이지에서 사용하는 폼·타임라인
  pages/           기획서 화면 및 Devices 기기 연결 페이지
  flows/CryFlow.tsx 울음 대응 흐름의 공통 상태
  styles.css       디자인 토큰·반응형 스타일
tests/domain.test.ts 핵심 상태 전이·데이터 격리 테스트
tests/deviceClient.test.ts 코드 검증·실패 처리·토큰 회전·API 범위 테스트
public/baby-demo.png 생성된 시연용 아기 이미지
```

일반 정적 호스팅으로 배포할 때는 모든 앱 경로를 `index.html`로 반환하는 SPA fallback을 설정하세요. Google Fonts 요청이 불가능하면 시스템 글꼴로 표시됩니다.

## 이미지

`public/baby-demo.png`는 내장 imagegen 도구로 생성한 가상의 아기 사진입니다. 실제 카메라 영상이 아니며 UI에 시연 이미지로 표시합니다. 생성 프롬프트는 `docs/image-prompt.txt`에 보관했습니다. 구름 마스코트·로고는 SVG로 구현했습니다.
